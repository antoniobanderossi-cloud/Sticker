## ⚠️ Потенциальные проблемы при запуске:

### 1. База данных
**Проблема:** Prisma клиент не сгенерирован
**Решение:** Запустить `npm run db:generate` и `npm run db:push`

### 2. Переменные окружения
**Проблема:** Отсутствует файл `.env`
**Решение:** Создать из `.env.example` и заполнить реальными ключами

### 3. API ключи
**Проблема:** Бот не запустится без валидных ключей
**Необходимо:**
- Telegram Bot Token от @BotFather
- OpenRouter API Key (с балансом)
- Replicate API Token (с балансом)

### 4. Модель AI
**Возможная проблема:** Модель `google/gemini-2.0-flash-001:free` может не поддерживать генерацию изображений
**Альтернатива:** Использовать платную модель если бесплатная не работает

### 5. Удаление фона
**Известная проблема:** Этап удаления фона пропущен (комментарии в коде)
**Причина:** Требуется загрузка файлов на CDN для работы с Replicate
**Текущее поведение:** Стикеры создаются с AI-сгенерированным фоном
